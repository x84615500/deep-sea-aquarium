# 深海優游 v0.41.2 觀賞模式修補

影片中水族箱已進入網頁滿版觀賞模式，但 Chrome 的瀏覽器工具列仍可見。原因是 `frame-ui.js` 將瀏覽器原生 `setTimeout`／`clearTimeout` 當成普通函式呼叫，Chrome 因此拋出 `Illegal invocation`，使按鈕事件在發出全螢幕請求前中止。

## 安裝

1. 將這個資料夾中的 `frame-ui.js` 放到 GitHub 專案根目錄，覆蓋同名檔案。
2. 提交更新後，在 Chrome 用 `Ctrl + Shift + R` 強制重新載入遊戲。
3. 點「進入水族箱觀賞模式」。若瀏覽器允許全螢幕，Chrome 工具列會隱藏；按 `Esc` 可離開。

本修補沿用 v0.41.2 的檔名與網頁版本，僅替換觀賞模式控制程式。測試版仍會在觀賞模式閒置 4.5 秒後淡出控制按鈕，觸碰或按鍵可再次顯示。
