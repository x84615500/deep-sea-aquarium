# 深海優游 v0.41.8｜存檔匯入相容修復

本版以 v0.41.6 完整遊戲為底，保留原有課程、魚種、主題、音樂、動畫、經濟、無障礙操作與存檔位置。上一包錯誤使用較舊的 v0.39 程式碼，且匯入器對舊課程版本限制過嚴，導致有效存檔被拒絕。

## 修正內容
- 接受已知較早課程排程版本並在載入時遷移。
- 修正對舊存檔課程開始時間與美人魚變體欄位的嚴格檢查。
- 匯入前先完成驗證和轉換，成功後才寫入；失敗不會覆蓋目前進度。
- 匯入前保留一份目前瀏覽器存檔備份；錯誤訊息會指出失敗原因。
- 移除原本 1 MB 的過低限制，最高接受 50 MB 存檔。
- 保留相同的瀏覽器存檔鍵 `starsea-aquarium-v1`。

## 更新 GitHub Pages
解壓後以此資料夾內所有檔案覆蓋 GitHub 專案根目錄，提交並推送。不要清除瀏覽器網站資料。部署完成後重新整理；若仍顯示舊版，Windows Chrome 請按 Ctrl + Shift + R。

## 匯入存檔
在最新版遊戲開啟「我的水族箱日常 → 存檔與操作 → 匯入存檔」，選擇遊戲匯出的 `深海優游-save.json`。
