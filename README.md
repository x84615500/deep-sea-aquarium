# 深海優游 v0.41.3｜美人魚素材更新版

本更新包以 GitHub 專案 `main` 分支最新版本 v0.41.2 為基底（來源 commit `8a524c4c06c604890516ba574e48e3d996238016`），保留該版已完成的遊戲內容、課程與資源規則，以及觀賞模式全螢幕修正。

## 本版更新

- 將繪圖修改後提供的 9 張美人魚 PNG，依遊戲使用的檔名放回 `assets/fish/`。
- 圖片畫布尺寸、透明像素、姿勢格位置均未由本次打包流程修改；素材檔案位元組與收到的圖檔相同。
- 更新網頁版本字樣與離線快取版本，避免瀏覽器繼續顯示舊素材。
- 其他魚種、遊戲程式、背景、音樂和全螢幕控制沿用 v0.41.2。

## 素材保護原則

`assets/fish/` 內的美人魚 PNG 是本版採用的原始美術素材。後續製作游動動畫時，請只改程式中的動畫邏輯／CSS，或另外建立衍生工作檔；不要直接覆寫這些原始 PNG。需要新畫格或重繪素材時，保留原始檔並另存新檔。

## 更新 GitHub Pages

1. 解壓縮此 ZIP，進入遊戲根資料夾。
2. 將根資料夾內的檔案與 `assets/` 資料夾更新到 GitHub 專案根目錄，覆蓋同名檔案。
3. 提交並推送更新後，在瀏覽器強制重新整理（Windows Chrome：`Ctrl + Shift + R`）。

玩家存檔仍保存在各自瀏覽器的本機儲存空間；本更新不會清除或改寫存檔。
