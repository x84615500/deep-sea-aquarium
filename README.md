# 深海優游 v0.41.4｜美人魚素材更新版

本更新包以 v0.41.3 完整遊戲為基礎，保留原有遊戲功能與存檔相容方式。

## 本版更新

- 一般「美人魚」：更新 `mermaid-sheet.png` 與 `mermaid-straight-sheet-v26.png`。
- 「魔物美人魚」：更新珊瑚粉、海綠、紫髮三種造型各自使用的身體／尾巴分層圖；另更新珊瑚粉完整圖。
- 素材依原 ZIP 對應檔名逐一放回遊戲路徑，未裁切、重繪或重新編碼。一般美人魚和魔物美人魚各自使用正確的素材，沒有互相覆蓋。
- 更新顯示版本、離線快取版本與美人魚素材網址版本，讓瀏覽器載入新圖。
- 其他魚種、課程、背景、音樂、存檔及全螢幕功能沿用 v0.41.3。

## 美術素材保護

`assets/fish/` 內本次更新的 PNG 為採用的原始素材。後續製作游動動畫時，請只調整 CSS／JavaScript 動畫或另存衍生檔，不要覆寫、裁切、調色或重新編碼這些原圖。

## 更新 GitHub Pages

1. 解壓縮 ZIP，將裡面的遊戲檔案和 `assets/` 資料夾覆蓋到 GitHub 專案根目錄。
2. 提交並推送更新後，瀏覽器重新整理；若仍顯示舊圖，請強制重新整理（Windows Chrome：`Ctrl + Shift + R`）。

玩家存檔仍保存在各自瀏覽器的本機儲存空間；本更新不會清除或改寫存檔。
