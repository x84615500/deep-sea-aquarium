# 深海優游

這是可部署至 GitHub Pages 的靜態遊戲網站。

## 發布方式

1. 將此資料夾作為 GitHub repository 的根目錄。
2. 在 repository 的 **Settings → Pages**，將 **Build and deployment → Source** 設為 **GitHub Actions**。
3. 推送到 `main` 分支後，`.github/workflows/pages.yml` 會自動發布。

玩家存檔保存在各自瀏覽器的本機儲存空間，可使用遊戲內的匯出／匯入功能轉移。

## v0.29 視覺更新
