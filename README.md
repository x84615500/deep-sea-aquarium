# 深海優游 v0.41.6｜美人魚隨機配色

以 v0.41.5 為基礎的完整遊戲更新包，保留既有存檔和遊戲功能。

## 本版更新

- 一般美人魚新增淺綠馬尾、淡黃色長髮、黑色長直髮造型，並搭配銀色或橘紅色魚尾。
- 魔物美人魚新增黑髮紅色比基尼、淺藍髮金黃色比基尼、淺藍髮橘黃色比基尼等組合。
- 已有美人魚會在首次載入新版時各自隨機更新一次外觀，同種類相鄰魚隻會避免相同造型；新購買的美人魚也會隨機選擇造型，並隨存檔保留。
- 所有原始 PNG 素材保持不變；本版新增的配色為獨立衍生素材，並加入離線快取。
- 更新顯示與快取版本至 v0.41.6，避免瀏覽器沿用舊檔。

## 更新 GitHub Pages

解壓縮後，以此資料夾內的檔案完整覆蓋 GitHub 專案根目錄，再提交並推送。載入舊畫面時，重新整理；若仍未更新，強制重新整理（Windows Chrome：Ctrl + Shift + R）。

玩家存檔仍位於各自瀏覽器本機儲存空間；覆蓋遊戲檔案不會清除存檔。
