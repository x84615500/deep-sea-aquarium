# 深海優游 v0.41.7｜存檔相容修復版

本版以 v0.41.6 完整遊戲為基礎修訂，保留課程、魚種、主題、音樂、動畫、經濟與無障礙功能。上一包錯誤使用較舊的 v0.39 遊戲程式，會讓 v0.41.6 存檔被舊版驗證器拒絕。本版恢復正確基底，保留相同的瀏覽器存檔鍵 `starsea-aquarium-v1`，並保留 v0.41.6 的存檔欄位與匯入格式。

## 更新方法

解壓後，把這個資料夾內的所有檔案與資料夾覆蓋到 GitHub 專案根目錄，提交並推送。不要刪除瀏覽器網站資料。部署完成後重新整理；若仍顯示舊版，請用 Ctrl+Shift+R 強制重新整理。

## 存檔恢復

- 若舊進度仍在同一瀏覽器的網站儲存空間，開啟更新後的遊戲會以原存檔接續。
- 若你之前匯出過 `深海優游-save.json`，請先部署本版，再到「我的水族箱日常 → 存檔與操作 → 匯入存檔」選取它。
- 如果你已在舊版重新建立新水族箱，新的進度可能已覆寫舊瀏覽器存檔；請保留任何舊 JSON 匯出檔。
